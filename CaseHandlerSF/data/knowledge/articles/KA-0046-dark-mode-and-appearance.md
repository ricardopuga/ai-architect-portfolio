## Dark mode

Dark mode arrived in release **2026.09.1** for the web and desktop apps. The mobile apps have had it since version 2.2.

**Web and desktop:** **Profile > Preferences > Appearance > Theme** gives three choices:

- **Light**
- **Dark**
- **Match system**, which follows the operating system's setting and switches automatically if the OS does (for example at sunset)

**iOS and Android:** **Settings > Appearance**. By default the app follows the device setting.

The setting is saved for each user and each device. Dashboards and charts switch to a dark-friendly color palette automatically.

## Other appearance settings

- **Density:** *Comfortable* or *Compact* rows in tables and boards.
- **High-contrast mode:** stronger borders and focus outlines (meets WCAG 2.2 AA).
- **Reduce motion:** turns off animations. Follows the OS setting by default.
- **Font size:** 90%–130%, for the app only, separate from browser zoom.

## Known limitations

- Emails and exported PDFs always use the light theme.
- Custom HTML blocks in documents may have colors set by their author that are hard to read in dark mode.
